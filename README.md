## Installation locale

1. Cloner le dépôt :

```bash
git clone https://github.com/Apoteoz/Projet-3.git
```

2. Accéder au dossier :

```bash
cd Projet-3
```

3. Ouvrir `src/index.html` dans un navigateur.

Aucune dépendance ni compilation n'est nécessaire.
